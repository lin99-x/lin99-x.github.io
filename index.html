Electricity Price Tracker

Built a full-stack serverless app on GCP processing real-time Swedish electricity spot prices across 4 market zones. Stack includes a FastAPI backend on Cloud Run (auto-scaling), a React frontend, and a BigQuery pipeline with MERGE/upsert patterns for 15-minute granularity data. A sliding-window algorithm identifies the cheapest charging windows, delivered via REST API to an interactive dashboard. CI/CD automated with Cloud Build and multi-stage Docker builds.
